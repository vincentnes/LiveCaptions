即時字幕 使用說明
==================

【它會做什麼】
在背景擷取「電腦播放出來的聲音」（影片、會議、直播…），偵測到有人說話時，
自動判斷語言並轉成文字，顯示在螢幕上你指定的位置，同時存成字幕檔。
可以選擇再加一行「第二語言」翻譯。

【安裝（每台電腦做一次）】
1. 把整個 LiveCaptions 資料夾放到固定的位置，例如 C:\LiveCaptions
   （放好後不要再搬動，否則桌面捷徑會失效；搬了就再跑一次 install.bat）
2. 點兩下 install.bat，等它跑完（需要網路）
   - 會自動判斷這台電腦有沒有 NVIDIA 顯示卡
   - 有：用 GPU + 大模型（較準，字幕會邊說邊出現）
   - 沒有：用 CPU + small 模型（說完一句才出現，約慢 1–3 秒）
   - 如果電腦沒有 Python，會自動安裝；裝完照指示再點一次 install.bat
3. 完成後桌面會有「即時字幕」圖示

【使用】
- 點兩下桌面「即時字幕」→ 出現控制面板，並自動開始錄製
- 按控制面板的大按鈕「開始錄製／停止錄製」
- 按控制面板右上角 ✕ 只會縮小到右下角工作列的圖示，程式仍在背景跑
- 右下角工作列的圖示：
    灰點 = 已停止，紅點 = 錄製中
    點一下（或兩下）圖示 → 叫出控制面板
    按右鍵 → 開始／停止錄製、開啟字幕檔資料夾、結束程式
- 已經在執行時再點桌面圖示，不會開第二個，而是把控制面板叫出來
- 快速鍵（可用可不用）：
    Ctrl + Alt + S  開始／停止錄製
    Ctrl + Alt + H  叫出控制面板

【看不到右下角的圖示？】
Windows 11 預設會把圖示藏在「^」箭頭裡。
設定 → 個人化 → 工作列 → 其他系統匣圖示 → 把「Python」打開，就會一直顯示。

【調整字幕位置】
控制面板 → 「調整字幕位置／大小」→ 直接拖曳字幕框，
拖右下角藍色方塊可改大小 → 按「✔ 完成調整」。
字幕平常是「滑鼠可以穿透」的，不會擋住你點底下的東西。
可以拖到第二個螢幕。

【字幕檔在哪裡】
「文件」資料夾裡的「即時字幕」資料夾，
每按一次開始錄製會產生一組：
  字幕_日期_時間.srt   （標準字幕檔，可以載入影片播放器）
  字幕_日期_時間.txt   （純文字，含時間和語言代碼）

【設定說明】
- 介面語言 / Language：控制面板左下角可切換中文或 English，立即生效。
  第一次開啟時，會依 Windows 的顯示語言自動選擇。
- 原文語言：一般用「自動偵測」。如果只聽某種語言、而偶爾被認錯，可以固定它。
- 第二語言：選了之後每句下面多一行翻譯。
- 翻譯方式（預設「自動」）：
    離線翻譯：在自己電腦上翻（Meta NLLB 模型，約 600 MB，安裝時下載），不需網路、沒有次數限制。
              有 NVIDIA 顯示卡很快；沒有也能用，慢一點。此模型授權為非商業使用。
    微軟翻譯／Google 翻譯：需要網路，品質較好，但可能被限制次數。
    「自動」會先用離線翻譯，不能用時自動改用網路翻譯；被限制次數的方式會暫停一陣子再試。
- 螢幕字幕顯示：原文＋翻譯／只顯示翻譯／只顯示原文。
  翻譯要等一句講完才會出來，所以翻譯那行會比原文慢一點，這是正常的。
  說的話本來就是目標語言（例如中文影片、翻成繁體中文）時，不會翻譯，直接顯示原文。
- 辨識模型：太慢跟不上時改成 base 或 tiny；要更準就改大一點。改完要結束程式再開。
- 中文一律顯示繁體字：Whisper 常輸出簡體，勾選就轉成繁體。

【音量關掉還錄得到嗎？】
- Windows 主音量調小／調到 0：大部分電腦照樣錄得到。
- Windows 按靜音：大部分電腦錄得到，少數音效卡會變成無聲，請自己試一次。
- 播放程式本身的音量調成 0（例如 YouTube 播放器靜音、音量混音器把那個程式調到 0）：
  錄不到，因為那個程式根本沒送出聲音。
- 想要「完全不出聲、但照樣有字幕」：安裝免費的 VB-CABLE（https://vb-audio.com/Cable/），
  把 Windows 的播放裝置切到「CABLE Input」。你聽不到，但程式照樣錄得到並顯示字幕。
  要恢復聲音時，把播放裝置切回喇叭／耳機即可。

【注意】
- 聲音來源預設是「全部播放裝置」：喇叭、耳機、藍牙耳機、HDMI 螢幕都會錄。
  插拔耳機、切換播放裝置時，程式會自動重新連接，繼續寫同一個字幕檔。
- 第一次安裝要下載模型；之後辨識完全在自己電腦上進行，不需要網路（翻譯除外）。
- 出問題時：點兩下 debug_run.bat 會顯示錯誤訊息；
  紀錄檔在 %APPDATA%\LiveCaptions\log.txt
- 想讓其他電腦也用：把這個資料夾（不含 venv 資料夾）複製過去，在那台電腦上跑 install.bat。
